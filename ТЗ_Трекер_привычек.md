# Техническое задание: Трекер привычек

**Рабочее название:** HabitFlow
**Позиционирование:** Русскоязычный трекер привычек без лимитов и платных ограничений на базовый функционал.
**Версия документа:** 1.0
**Статус:** Черновик для согласования

---

## 1. Анализ рынка и конкурентное окружение

### 1.1 Обзор конкурентов

| Продукт | Сильные стороны | Слабые стороны | Вывод для нас |
|---|---|---|---|
| **Loop** (Android) | Минимализм, расширенная статистика, гибкая настройка задач | Плохая оптимизация, вылеты | Берём минимализм + гибкость, но с надёжностью |
| **Habitica** | Геймификация (RPG), привычки как квесты, сильная мотивация геймеров | Перегруженный интерфейс | Геймификация опционально, не в ядре |
| **HabitShare** | Социальный трекер, шаринг прогресса, соревнования | Нет русского языка | Русский язык = наше преимущество |
| **Habitify** | Премиум-дизайн, кроссплатформенность | Лимит 3 привычки в бесплатной версии | Снимаем лимиты — ключевое УТП |
| **Avocation** | Визуальная метафора (полив растений), высокая вовлечённость | Узкая механика | Метафоры — как бонус-режим |
| **Streaks** | Фокус на стриках, качество iOS | Нет бесплатной версии | Бесплатный базовый слой + стрики |
| **Way of Life** | Глубокая аналитика, экспорт CSV/Excel | Устаревший UX | Экспорт данных в бесплатной версии |
| **Sinqly** | AI-коучинг, единая система целей жизни | Новый, незрелый, закрытый | Задел на будущее (v2) |

### 1.2 Позиционирование

**Одно предложение:** «HabitFlow — полностью бесплатный русскоязычный трекер привычек без лимитов, с гибкой настройкой и понятной статистикой.»

Три опоры позиционирования:
1. **Без лимитов** — неограниченное число привычек, целей, отметок, экспорта.
2. **Русский язык из коробки** — интерфейс, тексты, локализация дат, поддержка.
3. **Гибкость** — настраиваемые расписания, типы привычек, единицы измерения.

### 1.3 Целевая аудитория

- Новички в саморазвитии (18–35 лет), которым сложно с перегруженными приложениями.
- Бывшие пользователи Habitify/Streaks, уставшие от платных ограничений.
- Пользователи HabitShare, которым нужен русский язык.
- Люди с регулярными целями: спорт, чтение, вода, сон, отказ от вредных привычек.

## 2. Цели и границы продукта

### 2.1 Цели MVP

- Дать пользователю вести неограниченное число привычек бесплатно.
- Обеспечить отметку выполнения в 1–2 касания.
- Показать понятную статистику: стрики, прогресс, календарь.
- Работать офлайн с локальным хранением и последующей синхронизацией.

### 2.2 Что НЕ входит в MVP

- Социальная сеть и соревнования (v2).
- AI-коучинг (v3).
- Геймификация/RPG (v2).
- Нативные push в фоновом режиме iOS (ограничение платформы, решаем на этапе разработки).

## 3. Функциональные требования

### 3.1 Управление привычками (FR-1)

- **FR-1.1** Создание привычки без ограничения количества.
- **FR-1.2** Типы привычек:
  - «Сделать» (бинарная: выполнено/нет);
  - «Измеримая» (число + единица: литры, страницы, минуты, км);
  - «Воздержание» (не делать: курение, сладкое) — инвертированная логика;
  - «По расписанию» (конкретные дни недели / N раз в неделю / каждый день).
- **FR-1.3** Атрибуты привычки: название, иконка, цвет, категория, цель, единица, расписание, напоминания, заметка.
- **FR-1.4** Редактирование, архивация, удаление, переупорядочивание (drag & drop).

### 3.2 Отметка выполнения (FR-2)

- **FR-2.1** Быстрая отметка свайпом/тапом по карточке привычки.
- **FR-2.2** Ввод значения для измеримых привычек.
- **FR-2.3** Отметка задним числом (за прошлые дни).
- **FR-2.4** Отмена ошибочной отметки.
- **FR-2.5** Массовая отметка (несколько привычек за день).

### 3.3 Статистика и аналитика (FR-3)

- **FR-3.1** Текущий и максимальный стрик (серия).
- **FR-3.2** Процент выполнения за период (неделя/месяц/год).
- **FR-3.3** Календарь-хитмап (как в GitHub).
- **FR-3.4** Графики: динамика, распределение по дням недели, средние значения.
- **FR-3.5** Экспорт данных в CSV и Excel (без ограничений).
- **FR-3.6** Сводный экран «Обзор» по всем привычкам.

### 3.4 Напоминания (FR-4)

- **FR-4.1** Локальные уведомления на заданное время.
- **FR-4.2** Гибкие настройки: дни, повторы, тихие часы.
- **FR-4.3** Напоминание «добить» привычку вечером, если не отмечена.

### 3.5 Категории и организация (FR-5)

- **FR-5.1** Пользовательские категории (Здоровье, Учёба, Финансы и т.д.).
- **FR-5.2** Фильтры: все / активные / по категории / по расписанию на сегодня.
- **FR-5.3** Поиск по привычкам.

### 3.6 Данные и синхронизация (FR-6)

- **FR-6.1** Локальное хранение (работа офлайн).
- **FR-6.2** Регистрация/вход: email, Google, Apple.
- **FR-6.3** Облачная синхронизация между устройствами.
- **FR-6.4** Резервная копия и восстановление.
- **FR-6.5** Экспорт/импорт всей базы данных (JSON).

### 3.7 Настройки (FR-7)

- **FR-7.1** Тёмная/светлая тема.
- **FR-7.2** Язык интерфейса (русский по умолчанию, английский — опционально).
- **FR-7.3** Первый день недели, формат даты.
- **FR-7.4** Настройки приватности (аналитика, телеметрия — отключаемо).

## 4. Нефункциональные требования

- **NFR-1 Производительность:** запуск < 2 с, отклик на тап < 100 мс, плавность 60 FPS.
- **NFR-2 Надёжность:** отсутствие вылетов (учитываем слабость Loop); сохранение данных при сбое.
- **NFR-3 Офлайн-режим:** полный функционал отметки без сети.
- **NFR-4 Масштабируемость:** до 1000+ привычек и 10+ лет истории без деградации.
- **NFR-5 Доступность:** контраст, размеры тапов (min 44×44 dp), поддержка скринридеров.
- **NFR-6 Приватность:** соответствие 152-ФЗ; данные не продаются; экспорт и удаление по запросу.
- **NFR-7 Локализация:** все строки вынесены в ресурсы, даты/числа по локали.

## 5. Архитектура системы

### 5.1 Варианты реализации

| Вариант | Плюсы | Минусы | Рекомендация |
|---|---|---|---|
| Кроссплатформенный (Flutter) | Один код на iOS/Android/Web, быстрый старт | Размер приложения | **Рекомендуется для MVP** |
| React Native | Большая экосистема JS | Разнобой в нативах | Альтернатива |
| Нативные (Kotlin/Swift) | Максимальная производительность | Двойная разработка | Позже, при масштабе |
| Web-first (PWA) | Мгновенный доступ без магазинов | Слабее push/фон | Быстрый прототип |

### 5.2 Слои приложения (для Flutter)

```
┌─────────────────────────────────────────────┐
│              UI Layer (Widgets/Screens)      │
│  Home · HabitDetail · Stats · Settings       │
├─────────────────────────────────────────────┤
│            State / ViewModel Layer           │
│   Riverpod / Bloc — состояние и сценарии     │
├─────────────────────────────────────────────┤
│              Domain Layer                    │
│   UseCases · Entities · Бизнес-правила       │
├─────────────────────────────────────────────┤
│               Data Layer                     │
│  Repositories · Local DB (Drift/SQLite)      │
│            · Remote API · Sync Engine         │
└─────────────────────────────────────────────┘
```

Принципы: Clean Architecture, разделение слоёв, dependency inversion, тестируемость домена без UI.

### 5.3 Синхронизация

- Локальная БД — источник истины во время работы (offline-first).
- Каждая запись помечается `updated_at`, `deleted_at`, `sync_status`.
- Конфликты решаются по стратегии **last-write-wins** с ручным разрешением для текстовых полей.
- Очередь операций отправляется в облако при появлении сети.

### 5.5 Ключевые сущности домена

- `Habit` — агрегат-корень, управляет расписанием и типом.
- `Streak` — value object, рассчитывается из логов.
- `Schedule` — стратегия «попадает ли привычка в дату».
- `ProcessCheckIn` — use case отметки.

## 6. UX и экраны

### 6.1 Карта экранов

1. **Onboarding** — 2–3 экрана, объяснение ценности, быстрое создание первой привычки.
2. **Главный (Сегодня)** — список привычек на сегодня, отметка, прогресс дня.
3. **Карточка привычки** — стрик, календарь, график, заметки, редактирование.
4. **Статистика** — сводный обзор, графики, распределения, экспорт.
5. **Категории** — управление категориями и фильтрами.
6. **Настройки** — тема, язык, напоминания, данные, аккаунт.
7. **Архив** — архивные привычки.

### 6.2 Ключевые сценарии

- **Сценарий A (отметка):** открыть приложение → увидеть список на сегодня → тап/свайп → стрик обновлён за < 1 с.
- **Сценарий B (создание):** «+» → название → тип → расписание → напоминание → готово (за < 30 с).
- **Сценарий C (анализ):** «Статистика» → выбрать период → график → экспорт CSV.

## 8. План развития (roadmap)

### MVP (Месяцы 1–3)
- Создание/редактирование привычек без лимитов.
- Отметка, стрики, базовый календарь.
- Локальное хранение, тема, русский язык.

- Аккаунт и облачная синхронизация.

- Расширенная статистика и графики.

- Геймификация (уровни, достижения, визуальные метафоры).

### v3 (Месяцы 10+)

## 9. Метрики успеха

- **Активация:** ≥ 60% новых пользователей создают 2+ привычки в первый день.
- **Удержание:** D7 ≥ 35%, D30 ≥ 20%.
- **Вовлечённость:** ≥ 70% активных пользователей отмечают привычки ≥ 4 дней в неделю.
- **Качество:** crash-free sessions ≥ 99.5%.
- **Витрины:** рейтинг ≥ 4.5 в RuStore/Google Play.

---

## 10. Монетизация (без ущерба УТП)

- База — бесплатно и без лимитов (наше отличие).
- Премиум (опционально): темы оформления, расширенные отчёты, совместные челленджи, интеграции, приоритетная синхронизация.
- Никаких лимитов на число привычек, экспорт и историю.
