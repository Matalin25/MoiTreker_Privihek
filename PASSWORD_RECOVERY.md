# Восстановление пароля по email

На странице входа появилась ссылка «Забыли пароль?». Письмо содержит одноразовую
ссылку на 30 минут. В базе хранится только хэш токена. Успешный сброс делает
недействительными все ранее выданные ссылки этого аккаунта.

## Переменные Amvera (этап «Запуск»)

| Название | Значение |
| --- | --- |
| `HABITFLOW_PUBLIC_URL` | `https://moitrek-pri-alexander-25.mia0.amvera.tech` |
| `SMTP_HOST` | SMTP-сервер вашего почтового провайдера |
| `SMTP_PORT` | `465` для SSL либо `587` для STARTTLS |
| `SMTP_SECURITY` | `ssl` либо `starttls` (по умолчанию) |
| `SMTP_FROM` | Адрес отправителя, разрешённый провайдером |
| `SMTP_USERNAME` | Логин почты, обычно полный email |
| `SMTP_PASSWORD` | Пароль приложения почты — **секрет** |
| `SECRET_KEY` | Случайный постоянный секрет Flask — **секрет** |

Используйте пароль приложения, если почтовый провайдер требует его вместо обычного
пароля. Хост, порт и способ шифрования уточните в документации вашей почты.
После загрузки новой версии и сохранения переменных перезапустите контейнер.
Без настройки SMTP письма не отправляются; существующие пароли не меняются.

Для сохранения токенов при перезапусках используйте ту же постоянную SQLite-базу,
что и для аккаунтов (`HABITFLOW_DB`). Таблицы добавляются автоматически.

## Проверка

1. Запросите ссылку с email существующего аккаунта.
2. Проверьте входящие и спам, задайте новый пароль.
3. Войдите с новым паролем; старая ссылка больше не должна работать.

Ответ формы одинаков для существующего и неизвестного email. Ограничения:
не чаще раза в минуту на email и не более 5 принятых запросов за 15 минут с IP.
За обратным прокси IP может быть общим: настройку доверенных прокси следует
выполнять только зная конфигурацию Amvera, не доверяя произвольному X-Forwarded-For.
Почтовые таймауты могут влиять на время ответа формы.

Не включайте URL одноразовых ссылок в access-логи и внешнюю аналитику.
Сброс не завершает уже открытые сеансы на других устройствах.

Автотесты (временная база, SMTP замокан, реальные письма не отправляются):
`python -m unittest discover -s tests -v`
