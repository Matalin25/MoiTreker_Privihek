2. Создайте новый проект

5. Ветка: `main`

В настройках проекта Amvera добавьте следующие переменные:

| Переменная | Значение | Описание |
|------------|----------|----------|
| `TELEGRAM_BOT_TOKEN` | `8210487036:AAH9gMAk1TPWX3qL3hH5wfRufnvSs_DS6rk` | Токен от @BotFather (обязательно!) |
| `HABITFLOW_ENABLE_SCHEDULER` | `1` | Включить планировщик напоминаний |

**Опциональные переменные:**
| Переменная | Значение | Описание |
|------------|----------|----------|
| `HABITFLOW_DB` | `/data/habits.db` | Путь к базе данных (для persistent storage) |

| `LLM_URL` | `https://api.proxyapi.ru/v1/chat/completions` | URL API ProxyAPI |

### 4. Настройте persistent storage (опционально)

Чтобы база данных сохранялась между перезапусками:

1. В настройках Amvera включите **Persistent Volume**
2. Укажите путь монтирования: `/data`
3. Размер: 1 GB (достаточно для начала)
4. База данных будет храниться в `/data/habits.db`

### 5. Запустите деплой

1. Нажмите "Deploy" или "Запустить"
2. Дождитесь окончания сборки
3. Проверьте логи на наличие сообщений:

### 6. Проверьте работу

1. **Веб-интерфейс:** откройте URL приложения в браузере
2. **Telegram-бот:** отправьте `/start` в Telegram
3. **Настройки:** в веб-интерфейсе перейдите в `/integrations` и привяжите Telegram через API-ключ

1. Проверьте, что `TELEGRAM_BOT_TOKEN` задан правильно
2. Проверьте логи на наличие ошибок
3. Убедитесь, что бот не запущен локально (иначе будет конфликт)

## 🛠 troubleshooting

### Ошибка: "TELEGRAM_BOT_TOKEN не задан"
- Добавьте переменную `TELEGRAM_BOT_TOKEN` в настройках Amvera
- Перезапустите приложение

### Бот не отвечает в Telegram:
- Проверьте, что бот не запущен локально (остановите локальный бот)
- Проверьте логи на наличие ошибок подключения к Telegram API
- Убедитесь, что токен правильный

### База данных сбрасывается:
- Включите Persistent Volume в настройках Amvera
- Установите `HABITFLOW_DB=/data/habits.db`

### Напоминания не работают:
- Убедитесь, что `HABITFLOW_ENABLE_SCHEDULER=1`
- Проверьте, что у пользователей настроено время напоминаний
- Проверьте логи на наличие сообщений о рассылке
